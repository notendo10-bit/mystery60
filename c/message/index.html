MYSTERY 60｜失踪ミステリー

最後のメッセージ

十二月九日、午後七時十二分。妹からLINEが届いた。

「今、駅に着いた。歩いて帰るね」

ホームの写真が一枚ついていた。妹がいつも使っている駅だ。家までは歩いて十五分。妹は帰ってこなかった。スマホの電源は、それきり入っていない。

翌日、妹の周りの人に話を聞いた。

同僚の女性はこう言った。「七時ちょうどに会社の前で別れました。退勤の打刻も七時です」

恋人の佐伯さんは、目を赤くしていた。「あの夜は駅で待ち合わせてたんです。ホームで写真を撮って、お姉ちゃんに送っとくって。そのあと改札まで一緒に歩いて、そこで別れました。ひどい雨だったのに、送っていけばよかった」

駅の防犯カメラは、先月からの工事で止まっていたという。私はもう一度、あの写真を開いた。

手がかり

  • 十二月九日は朝から夜中まで雨だった。
  • この季節、日没は午後四時半ごろ。七時はもう真っ暗だ。
  • 会社から駅までは歩いて二十分かかる。
  • 写真のホームの床と、手前から伸びているものをよく見る。

この中で、確実に嘘をついているのは誰？
