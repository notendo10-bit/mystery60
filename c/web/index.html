MYSTERY 60｜心理ホラー

窓の外の女

山あいの古い民宿に、ひとりで泊まった。部屋は二階の角で、窓の外は真っ暗な杉林だった。

夜中の二時、喉が渇いて目が覚めた。枕もとの明かりをつけて起き上がった。

窓の外に、女の顔があった。

髪の長い、白い顔が、ガラスの向こうから、じっとこちらを見ていた。悲鳴をあげて目をそらし、もう一度見ると、顔はなかった。

朝、宿の主人は首を振った。「二階の窓の外に、人は立てませんよ。足場がない」

手がかり

  • 朝、窓を開けようとして気づいた。窓の外側いっぱいに、大きなクモの巣が張っていた。破れたところは、ひとつもない。
  • 宿の主人によると、この窓のクモは、毎晩、夕方に巣を張り直す。前の晩も、夕方には巣があったという。
  • 夜、部屋の明かりをつけると、外が真っ暗な窓には、部屋の中がはっきり映る。
  • 顔が見えたとき、明かりは私の後ろの枕もとでついていた。
  • 部屋の戸は、ふすま一枚。鍵はない。

窓に見えた女の顔は、どこにあった？
